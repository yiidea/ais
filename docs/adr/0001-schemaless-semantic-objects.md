# ADR-0001：采用无模式语义对象而非强 Schema

- **状态**：已接受
- **日期**：2026-10-30

## 背景

AI 负载（Agent 记忆、RAG、多模态）的数据形态是半结构化 + 语义的。内容往往在写入时才能确定结构，且语义标签本身可能由模型生成。如果强制 schema：

- 写入前需要人工建模，模型生成的新字段无法落地；
- 导致「语义信息被压成强类型」的信息损失；
- 每次模型能力变化都会引发 schema 迁移。

## 决策

采用 **SemanticObject** 作为核心对象：原文 + 向量 + 稀疏 tags + 溯源，**不强制 schema**。模式可以以「模板」形式存在，只用于索引优化与提示，不用于约束。

## 后果

**正面**
- 写入路径极短，模型可直接写任意结构。
- 多模态天然支持（一层 modality 标签）。
- 索引可随负载演进，新增索引从日志回放构建。

**负面**
- 失去数据库层面的「唯一约束」「外键」等保障 → 需要靠语义幂等、溯源、冲突模型补齐。
- 用户查询可能因「数据没结构」而变得更依赖规划器。

**缓解**
- 提供可选的 `tag schema` 校验（仅警告，不拒绝）。
- 在规划层提供「常见意图模板」，把常用的结构化语义当成一等公民。
