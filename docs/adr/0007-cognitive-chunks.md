# ADR-0007：使用认知块（Cognitive Chunk）作为返回单位

- **状态**：已接受
- **日期**：2026-10-30

## 背景

LLM 的上下文窗口是 AI 应用最稀缺的资源。传统数据库返回行，应用需要自己去拼、去重、排序、压缩，结果往往浪费大量 token，或者遗漏关键证据。

## 决策

引擎的返回单位是 **认知块（Cognitive Chunk）**：语义自洽、带置信度、带溯源引用、已按注意力密度打包的最小上下文单元。`pack` 算子在没有 token 预算显式给出时，使用域默认预算。

## 备选方案

1. 返回原始行 / 候选列表 → 应用层自行处理，token 浪费大。
2. 返回完整文档 → 无法满足 token 预算。
3. 返回摘要 → 丢失证据细节，且摘要成本高。

## 后果

**正面**
- 大幅降低上下文浪费。
- 结果自带证据引用，利于可解释性与审计。
- 与溯源、置信度、冲突模型自然结合。

**负面**
- 返回格式比「行」更重，不适合纯结构化读取。
- 打包需要计算注意力密度，增加少量 CPU。

**缓解**
- 同时提供原始对象读取接口，供需要精确数据的场景使用。
- 密度计算仅在召回路径，且可缓存。
