# 09 — 威胁模型

面向「模型参与读写」的存储系统，威胁面比传统数据库更大。本文按 STRIDE 列出主要威胁、缓解手段和残余风险。

## 1. 资产

| 资产 | 敏感性 |
|---|---|
| 原始语义对象（用户数据） | 高 |
| 溯源图（来源、模型、时间） | 高（可反推行为） |
| 索引（embedding、关键词语料） | 中（可推断） |
| 规划器提示（catalog 摘要、统计） | 中 |
| 审计日志 | 最高（不可篡改） |

## 2. STRIDE 分析

### 2.1 Spoofing（身份伪造）

| 威胁 | 缓解 |
|---|---|
| 伪造 writer 身份写溯源边 | 边签名（Ed25519）；引擎验签 |
| 伪造 causal token 跨节点读取 | 令牌使用 HMAC 或签名 |
| 客户端冒充 SDS 服务 | mTLS |

残余风险：签名密钥泄露；由密钥轮换与最小权限缓解。

### 2.2 Tampering（篡改）

| 威胁 | 缓解 |
|---|---|
| 直接修改日志文件 | 记录 CRC + 段级 Merkle + 签名，启动时校验 |
| 篡改索引段 | 索引段同样 Merkle 校验，重建自日志 |
| 篡改规划器返回的 DSL | DSL 由模型输出，Verifier 只认白名单；执行前再校验签名/来源 |
| 重放旧写入 | `idempotency` + epoch 单调；审计日志比对 |

### 2.3 Repudiation（抵赖）

| 威胁 | 缓解 |
|---|---|
| 否认某次写入 | 审计日志 append-only + 签名 |
| 否认冲突 | ConflictSet 带来源与时间，不可删 |

### 2.4 Information Disclosure（信息泄露）

| 威胁 | 缓解 |
|---|---|
| 跨域越权读取 | 域级 + 标签级 ACL；Verifier 检查域权限 |
| 通过 embedding 反推原文 | 加密存储；向量加密索引（受控的解密后计算或同态/安全多方）——v1 仅做访问控制，v4 安全计算 |
| 规划器提示泄露数据 | 规划上下文只含 catalog 摘要，不含原始内容 |
| 通过溯源推断私有知识 | 溯源可见性继承对象可见性；返回前过滤 |

### 2.5 Denial of Service（拒绝服务）

| 威胁 | 缓解 |
|---|---|
| 超大意图拖垮规划器 | 意图长度上限、意图分类前置、模型调用限流 |
| 规划器生成病态计划（O(n²) 遍历） | Verifier 资源上限、图遍历深度上限、计划预算 |
| `pack` 阶段大量候选 | `max_candidates` 预算 |
| 慢查询占用 IO | 域 IO 权重、队列分离 |

### 2.6 Elevation of Privilege（权限提升）

| 威胁 | 缓解 |
|---|---|
| 规划器 DSL 注入危险算子 | 算子白名单；不支持任意代码执行 |
| 通过标签注入越权查询 | 标签值是数据，不是语法；参数化 |
| 后台 consolidation 调用模型时被提示注入修改记忆 | consolidation 的输出必须形式化为写请求并走同样权限校验；原文与指令严格分隔 |
| 提示注入污染记忆 → 后续被召回执行 | 内容安全层打 `injected` 标记；返回时隔离；高风险域禁止自动采纳 |

## 3. 提示注入专项

存储系统面对的「数据即指令」问题：

1. **写入时隔离**：所有 payload 都是数据，不会被当作指令执行；规划器只接受 intent 而非 payload。
2. **召回时标记**：来自不可信来源的内容带 `untrusted` 标记，SDK 默认放在隔离字段，不直接并入系统提示。
3. **建模威胁**：即使内容被注入到上下文，引擎层面的风险限于「数据污染」——通过溯源、冲突组、置信度降低其影响。
4. **内容安全层**：可选插件做检测（PII、恶意指令），结果作为标签存储。

## 4. 供应链

- 模型：规划器使用的模型需要固定版本 + 校验（模型哈希）。
- 依赖：SDK / 引擎依赖使用锁定版本 + SBOM。
- 插件：规划器、reranker 插件加载前验证签名。

## 5. 审计与取证

- 审计日志独立存储、append-only、定期签名快照。
- 支持从任意历史时刻重建可见世界状态（结合 MVCC + 溯源）。
- 删除操作记录墓碑，内容擦除但存在性与时间保留（满足合规）。

## 6. 残余风险与后续

| 残余风险 | 后续方向 |
|---|---|
| 向量反推攻击 | 加密向量索引、安全计算（v4） |
| 跨域侧信道 | 隔离域到独立进程/节点 |
| 模型本身被投毒（规划器输出偏差） | 计划 A/B 校验、确定性回退 |
| 签名基础设施被攻破 | HSM / 云 KMS 托管、双人审批 |
